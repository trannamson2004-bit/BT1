Về dự án này

Website bài tập 24 — Đề thi Kết thúc học phần “Lập trình Web”, Đề số 1. Xây dựng hoàn toàn bằng HTML, CSS, JavaScript thuần, không dùng framework.

Công nghệ sử dụng

  • HTML5 (semantic tags, form validation)
  • CSS3 (Flexbox, Grid, biến CSS, animation, responsive)
  • JavaScript ES6+ (DOM, Event, LocalStorage, setInterval)
  • Deploy tĩnh: GitHub Pages / Netlify
